1产品概述

Universal Scene Forge（USF）是一款 Windows 桌面端一体化场景重建与导出工具： 把一段实拍视频或一组照片变成带纹理的 3D 网格模型，并自动导出为 FBX / OBJ / GLB / .blend / .uasset 等主流 DCC 格式。

一句话定位：以 3D 高斯泼溅（3D Gaussian Splatting）为重建内核， 以 Blender / 3ds Max / Maya / Houdini / Cinema 4D / Metashape / UE5 等 DCC 软件的无头桥接 为后处理管道的「视频 → 可用 3D 资产」生产线。

核心能力

  • 一键重建：视频/图像序列输入 → 抽帧 → SfM 位姿求解 → 3DGS 训练 → 泊松网格重建 → LOD 减面，全自动。
  • 16 款 DCC 软件自动探测：环境变量 → 注册表 → 常见安装路径三级探测，绿灯即代表就绪。
  • 五级 FBX 导出降级链：Blender → 3ds Max → Maya → Houdini → Cinema 4D，前一个缺席或失败自动切换下一个。
  • 容错不中断：任何 DCC 步骤失败只亮红灯并写日志，主流程继续，总能拿到 OBJ/GLB 保底产物。
  • 缺什么补什么：依赖体检 + 官方便携版自动安装（Blender / FFmpeg / COLMAP）。

2快速上手

从安装到拿到第一个模型，全程约 10–40 分钟（取决于视频长度与显卡）。

  1. 安装软件
    双击 UniversalSceneForge_Setup.exe 按向导完成安装；也可使用免安装的绿色版目录， 直接双击 UniversalSceneForge.exe 启动。
  2. 首次运行 · 依赖体检
    点击左侧工具栏 依赖体检，顶部结论行会直接告知「依赖够不够执行这个软件」， 表格分 Python 库 / 系统工具 / GPU 驱动 / 训练环境四类逐项列出状态。 缺失的 Python 库可一键安装（6 个 pip 下载源任选：清华 / 阿里 / 腾讯 / 中科大 / 华为 / 官方直连）； 缺 FFmpeg / COLMAP 时点击 安装缺失工具，同意后经多源回退自动下载官方便携版； 训练环境未初始化时，点击 一键创建训练环境 即可全自动安装。详见 第 8 章。
  3. 添加输入源（支持多选）
    点击 添加文件…（按住 Ctrl / Shift 可混合多选）添加 环绕拍摄 的视频 （MP4 / MOV / MKV / AVI / WebM 等 13 种格式；15–60 秒、光线稳定、避免纯色背景） 与 JPG / PNG / WebP 图片；点击 添加目录… 可一次选中多个图像序列文件夹； 也可直接把多个文件与文件夹批量拖入窗口。 视频与图片可混合添加、同时输入——多个视频会各自抽帧后合并，详见 第 3 章「多源输入」。
  4. 设置参数（可选）
    一般保持默认即可：抽帧帧率 2 fps、抽帧上限 300、3DGS 迭代数 30000。 想快速预览效果可把迭代数降到 7000。三项参数均不设上限： 抽帧上限填 0 = 不限制（抽取全部帧），帧率与迭代数可按需填大值。
  5. 点击「▶ 开始重建」
    右侧进度条依次经过 9 个阶段；期间各 DCC 指示灯会实时变黄（执行中）→ 变绿（完成）/ 变红（失败跳过）。
  6. 收产物
    完成后在输入源同级的 usf_work/output/ 目录中收取模型： usf_scene.obj（主网格）、usf_scene_lod1/2.obj（减面版）、 usf_scene.fbx / .glb / .blend 等导出物。
拍摄建议
拍摄时以目标物为圆心环绕 1–2 圈，快门速度足够高避免运动模糊；光照稳定、避免玻璃/镜面/纯黑纯白区域， SfM 求解成功率会显著提高。

重建进度反馈区

主窗口右侧顶部是重建进度的实时反馈区，点击「▶ 开始重建」后从上到下由四部分组成：

  • 阶段标题行 —— 左侧显示当前阶段名（如「DCC 后处理」），右侧显示「阶段 n/8」计数；
  • 总进度条 —— 绿色填充的 0–100% 总进度，各阶段对应的百分比区间见第 4 章流水线表；
  • 8 段步骤条 —— 采集 → SfM → 训练 → 网格 → UE5 → 后处理 → 修复 → 导出， 每个阶段一枚胶囊标签，状态随流水线实时流转（见下表）；
  • 动态消息行 —— 显示当前动作，如「Blender: 去重 / 删松散面」「3DGS 迭代 18200/30000」。
标记状态含义
○ 阶段名待执行（灰）流水线尚未推进到该阶段
● 阶段名执行中（黄）该阶段正在运行，日志控制台有实时输出
✓ 阶段名已完成（绿）该阶段成功结束
✗ 阶段名失败跳过（红）该阶段出错，主流程已自动跳过并继续后续阶段
失败反馈
阶段失败或重建异常终止时，除步骤条标红 ✗ 外，软件还会弹出醒目提醒窗口， 汇总失败原因并给出常见修复建议（用「设置 → 依赖体检」安装缺失组件、降低迭代数或减少输入帧数）； 详细错误可在日志控制台和 usf_work/logs/ 中查看。全部成功完成时不弹窗，进度条停在 100%。

多源输入（多个视频与图片同时输入）

输入源面板已从单一路径升级为多源列表，支持把多个视频文件、图像目录与单张图片 混合添加、同时输入，一次重建即可融合全部素材：

  1. 添加源 —— 添加文件…（文件对话框中按住 Ctrl / Shift 可混合多选视频与图片）、 添加目录…（目录对话框中按住 Ctrl / Shift 可一次选中多个目录）， 或直接把多个文件与文件夹批量拖入主窗口；重复添加同一路径会被自动忽略。
  2. 管理源 —— 列表中选中一行或多行后点 移除所选，或 清空 全部； 拖入 / 添加的顺序即处理顺序，可随时增删后再次点「▶ 开始重建」。
  3. 开始重建 —— 各源按以下规则合并为统一帧序列：
    源类型处理方式
    视频（MP4/MOV/AVI/MKV/WMV/M4V/WebM/FLV/MPG/MPEG/TS/M2TS/MTS） 各自抽帧到 usf_work/frames/<视频名>_NN/ 独立子目录，互不覆盖；帧率与上限取「重建参数」设置
    图像目录按文件名排序后整目录收集（JPG/JPEG/PNG/BMP/TIF/TIFF/WebP）
    单张图片直接并入帧序列（含 WebP）
    合并后自动去重（同一路径只算一次），再统一进入预处理 → SfM → 3DGS 训练。
多源容错规则
  • 某个源失败（视频损坏、目录为空、路径不存在）只跳过该源并记入日志，不影响其余源；
  • 全部源都无产出时，输入采集阶段才报错；
  • 工作目录 usf_work/ 跟随列表中第一个源所在位置（文件取同级、目录取子级）；
  • 多视频时注意总帧数 = 各视频抽帧数之和，「抽帧上限」对每个视频独立生效（填 0 = 全部不限制）， 建议单次重建总帧数控制在几百帧量级，避免过多帧数拖慢 SfM 与训练。

Premiere Pro 高效抽帧（输入预处理）

对于码流特殊、ffmpeg / OpenCV 解码不稳，或需要先剪辑、调色再导帧的视频， 可改用 Adobe Premiere Pro 的解码器批量导帧（v0.9.3 起）：

  1. 生成任务 —— 菜单 文件 → Premiere Pro 高效抽帧… 打开对话框， 输入源列表中的视频会自动带入（也可在对话框内继续增删）；设置抽帧帧率、上限与 帧输出目录后点 生成任务并启动 Premiere —— 首次使用会自动安装 「USF 抽帧导出」CEP 扩展并启用加载权限；
  2. 面板导出 —— 在 Premiere 中打开 窗口 → 扩展 → USF 抽帧导出， 点「① 自动导入并导出全部视频」即可逐个视频自动建序列并按设定帧率导出 JPEG； 也可先把素材拖入时间线手动剪辑，改用「② 仅导出当前序列」（支持入出点范围）；
  3. 回填输入源 —— 导出完成后，帧目录会自动加入主程序输入源列表， 后续流程与普通图像目录完全一致。
PR 抽帧说明
  • 需要 Premiere Pro 2019（13.0）及以上版本；扩展安装于 %APPDATA%\Adobe\CEP\extensions\，仅写入当前用户目录，无需管理员权限；
  • 多视频的帧名前缀自动区分（frame_v1_00000.jpg、frame_v2_00000.jpg…）， 同一输出目录互不覆盖；
  • 主程序对话框与 PR 面板通过任务 / 状态文件联动：对话框实时显示导出进度， 可随时「发送停止指令」；
  • PR 面板按 4 帧一组分块导出，导出过程中 Premiere 界面保持可操作。

4重建流水线详解

点击「开始重建」后，数据依次经过 9 个阶段。每个阶段都有独立超时看门狗与容错包裹—— 单阶段失败不会中断整体流程，只影响对应产物。

#阶段做什么产物进度区间
1INGEST 抽帧FFmpeg 按设定帧率从视频抽帧；并行预处理（缩放到最长边 1600px）frames/*.jpg0–10%
2SFM 位姿求解COLMAP 特征提取 → 全量匹配 → 稀疏重建，求出每帧相机位姿sparse/0/*.bin10–20%
3TRAIN 3DGS 训练gaussian-splatting 官方实现训练高斯场（独立 Python 环境子进程）point_cloud.ply20–55%
4MESH 网格化SH 系数 → 顶点色；不透明度过滤 → 泊松重建 → 密度裁剪 → LOD 减面usf_scene.obj + LOD55–65%
5UE5 预览中间 OBJ/FBX 推送到 UE5 工程 /Game/USF 并保存 .uassetUE5 内资产65–70%
6DCC 后处理Blender 无头模式：去重/删松散面/重算法线 → 智能 UV → 顶点色材质 → 导出FBX/GLB/BLEND70–85%
7修复（可选）Metashape Pro：对齐照片 → 稠密云 → 建模 → 空洞修复（需授权，默认关闭）修复版 OBJ—
8EXPORT 导出分发按勾选的格式分发导出；FBX 走五级降级链output/ 全部产物85–100%
耗时参考（RTX 3060 / 30 秒视频 / 30000 迭代）
抽帧约 1 分钟 · SfM 约 3–8 分钟 · 3DGS 训练约 15–25 分钟 · 网格化约 2 分钟 · 后处理与导出约 2–5 分钟。迭代数降为 7000 可将训练压缩到约 5 分钟（质量略降）。

取消与超时

  • 点击 ■ 取消 后，软件会终止所有子进程树（taskkill /T /F）并安全停止。
  • 每个 DCC 步骤都有超时看门狗（默认：Blender/Max/Maya 60 分钟，Houdini/C4D 30 分钟，UE5 15 分钟，Metashape 4 小时）。 超时自动杀进程并切换降级方案。

面向安装位置非标准（便携版、绿色解压版、多版本共存）的场景，USF 提供 「项目调用路径」对话框：为任意 DCC 软件手动指定可执行文件路径， 手动路径优先级最高，留空则回退三级自动探测。

  1. 打开对话框
    菜单栏 设置(S) → 软件调用路径…（标准入口），或点击主界面左侧 调用路径设置 快捷按钮——两者打开同一对话框。

  3. 手动指定路径
    在第三列输入框中填写（或点击 浏览… 选择）该软件的调用入口，例如：
    软件应选择的 exe

    点击 保存并重新探测，设置立即写入 settings.json， 主窗口指示灯矩阵自动刷新。也可用 清除 恢复单个软件自动探测， 或 全部恢复自动 清空所有手动路径。

DCC 扩展一键安装

USF 桥接的 16 款 DCC 大多通过命令行调用（随包分发，无需装入宿主）；但个别功能需要把 扩展面板装入宿主软件本体，例如 Premiere Pro 的「USF 抽帧导出」CEP 面板。 这类扩展由体检表的 DCC 扩展 区段统一管理（琥珀色 ◐ 标识）：

  • 宿主未安装 —— 显示「暂不需要」，无需任何处理（例如未装 Premiere 时 CEP 面板没有意义）；
  • 已装入 —— 显示「已装入 <宿主名>」，就绪；
  • 待安装 —— 宿主已装但扩展未装，点击对话框下方的 「安装全部 DCC 扩展」 按钮即可。

一键安装从安装包内置的 extensions\ 目录本地复制到宿主的用户级扩展目录 （如 Premiere 的 CEP extensions 目录），并自动写入 PlayerDebugMode 注册表以放开面板加载权限—— 全程无需联网、无需管理员权限；单个扩展失败不影响其余，结果逐行回显在对话框控制台。 后续版本接入更多宿主扩展时，体检表与该按钮会自动纳入，UI 无需改动。

训练环境（3DGS 训练链）

体检表新增训练环境三行：仓库（train.py 就绪）、训练 venv（.venv 创建）、torch+CUDA（后台子进程探测，数秒后回填结果）。 未初始化时，点击对话框下方的 「一键创建训练环境」 按钮，确认后软件即全自动完成下载与安装：

  1. 预检：探测 VS C++ 生成工具与 CUDA Toolkit（编译子模块必需，缺失时仅警告并给出安装指引，不阻断）；
  2. 创建 venv：在 安装目录\external\gaussian-splatting\.venv\ 创建独立虚拟环境（不影响系统 Python）；
  3. 安装 torch+CUDA：从官方 cu128 源下载安装（约 3 GB），官方源失败自动回退交大镜像（同一 cu128 整库镜像）；
  4. 编译安装 3 个 CUDA 子模块：diff-gaussian-rasterization / simple-knn / fused-ssim（本机编译，约 5–20 分钟）；
  5. 验证：子进程导入 torch 并检查 CUDA 可用性，成功后自动写入「软件调用路径」（gs_python），即可直接开始重建。

全程输出实时滚动在对话框控制台；任何一步失败都会中止并给出对应的修复指引（装哪一步断的，重按按钮即从断点续装，已装组件自动跳过）。 全程约 10–40 分钟（取决于网速）。需要系统装有 Python（推荐 3.12 x64）。 也可点击「复制手动命令」获取等价命令块，在 CMD 中逐行执行：

cd /d <安装目录>\external\gaussian-splatting
py -3.12 -m venv .venv
<安装目录>\external\gaussian-splatting\.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
<安装目录>\external\gaussian-splatting\.venv\Scripts\python.exe -m pip install "<仓库>\submodules\diff-gaussian-rasterization" "<仓库>\submodules\simple-knn" "<仓库>\submodules\fused-ssim"
torch 源与显卡架构
命令使用 cu128 源：覆盖 Volta～Hopper 及 Blackwell（RTX 50 系, sm_120），且 CUDA 12.x 轮子对驱动的兼容面最广。老版 cu121 源不支持 RTX 50 系。venv 固定 3.12（与软件内核同版， torch 轮子覆盖最稳）。编译三个 CUDA 子模块另需 MSVC 编译器（Visual Studio Build Tools 的 C++ 工具集）与 CUDA Toolkit（nvcc），一键安装的预检与失败提示会明确指出所缺组件。
为什么训练环境独立？
torch+CUDA 运行时超过 5 GB 且随显卡型号变化，打包进安装包不现实。 GUI 安装包保持 100 MB 以内，训练环境按需创建、与界面隔离，显卡升级后只需重建训练环境。
安全策略
所有自动安装默认先弹窗征得同意；Blender / FFmpeg / COLMAP 仅使用官方便携版 zip 与官方镜像（免管理员权限）。 如需完全静默安装，可在 settings.json 中将 allow_silent_install 设为 true。

10常见问题 FAQ

点了「开始重建」好像没反应？
正常启动的标志：按钮立即禁用、8 段步骤条复位为灰色 ○、消息行显示「正在启动流水线…」、 日志控制台开始滚动输出。若瞬间弹窗提示失败，多为依赖缺失——先到 设置 → 依赖体检与一键安装 补齐 COLMAP / FFmpeg；若界面完全无变化，检查输入源列表是否为空（列表为空时点开始会弹提示）。
点了开始重建，进度条一直停在 20% 左右？
20–55% 区间是 3DGS 训练阶段，通常耗时最长（15–25 分钟属正常）。观察日志中 「3DGS 迭代 n/30000」是否在增长；确认 GPU 指示灯为绿色（无 CUDA 时会退化为 CPU 模式，慢 10–50 倍）。
某软件指示灯是灰色的，需要装上它才能用 USF 吗？
不需要。灰灯只表示「该软件未安装」。USF 的保底产物（OBJ + GLB）完全本地生成， 不依赖任何 DCC。Blender 缺席时 FBX 才会尝试 3ds Max → Maya → Houdini → C4D 降级链； 全部缺席则跳过 FBX，OBJ/GLB 照常输出。
红色指示灯代表软件坏了？
红等表示该步骤调用失败，常见原因：软件无授权（Metashape/C4D）、版本不兼容、 超时被看门狗终止。主流程已自动跳过并写日志，查看日志控制台中对应的 [ERROR] 行即可定位。
SfM 阶段失败（日志提示 mapper 退出非零）？
通常是视频纹理太弱、运动模糊或光照剧变导致特征匹配失败。换一段环绕、稳定、纹理丰富的视频 （避开白墙/玻璃/纯色物体），或降低抽帧率提高单帧质量。
自动安装下载太慢或失败？
网络受限时可手动下载便携版（Blender / FFmpeg / COLMAP 官网 zip），解压到任意目录后， 在「调用路径设置」中手动指定 exe 路径即可，效果与自动安装完全一致。
输出的模型有破洞/浮空碎片？
① 勾选「Metashape 洞穴修复」（需 Pro 授权）；② 在 settings.json 调低 opacity_threshold（如 0.25）过滤更多离群高斯；③ 保证拍摄覆盖完整（底部/背面也要拍到）。
UE5 预览没反应？
UE5 推流需要本机有可用 UE5 工程与对应版本。确认 UE5 指示灯为绿色，并在 「调用路径设置」中确认 UnrealEditor-Cmd.exe 路径正确。UE5 缺席只影响预览，不影响任何导出产物。
在哪里改界面里没有的参数（泊松深度等）？
编辑安装目录下 settings.json（见第 5 章高级参数表），保存后重启软件。
