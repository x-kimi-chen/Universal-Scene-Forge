# 0.9.7 调研纪要: 高斯泼溅生态与网格质量方向 (2026-09-29)

## 网格提取方法演进 (质量路线)
- **SuGaR** (CVPR, Guédon & Lepetit): 表面对齐正则 + 泊松提取 + UV 纹理 —— 经典基线;
  需要训练期正则 (external 仓库改动, 许可允许自用)。
- **2DGS**: 2D 面片高斯 + TSDF 深度融合, 几何保真优于 3DGS; 同样是训练期方法。
- **MILo** (Guédon 2025): 高斯与网格双向一致性联合优化, 当前学术最优之一。
- **实践结论**: 训练期方法需要替换/扩展 external 训练仓库 —— 0.9.7 以后评估;
  当下提升抓手的优先级是后处理 (已实装) 与主体遮罩 (已实装)。

## 训练引擎生态 (兼容矩阵依据)
- **nerfstudio 1.x**: splatfacto 需 gsplat; PLY 导出经 ns-export; USF 已实装。
- **OpenSplat** (WebODM 组织): 活跃更新, 无 Windows 预编译 —— 需自编译。
- **Postshot** (Jawset): Windows 最易用的商业方案, CLI 待装机联调。
- **COLMAP 4.1.0**: 新 CASPAR 全局求解器大幅提速 —— 值得升级适配 (0.9.7+ 评估,
  保持 3.9.1 为稳定默认)。
- **gsplat** (nerfstudio-project): CUDA 光栅化库, 独立脚本可复现官方 3DGS 指标。

## 主体分割/遮罩最佳实践
- 多视图一致的遮罩是关键 (不一致 → 浮动伪影); SAM 逐帧分割需跨视图 ID 一致性。
- **遮罩边界收紧** (腐蚀 + 最大连通域) 已实装 —— 投影过滤精度直接受益。
- 训练后剪枝 (post-training pruning) 是遮罩质量不足时的有效兜底 ——
  USF 的主体高斯投影过滤即属此类, 与 2026 论文方向一致。
- 训练期遮罩损失 (mask loss) 是更彻底的方案, 需 external 仓库自用修改。

## 拍摄侧建议 (用户引导, 影响大于算法)
- 主体补光 (暗色物体必须); 深色纯色背景; 缓慢匀速环绕 + 保持对焦;
  60% 以上画面覆盖主体; 避免失焦段 (USF 已自动剔除)。
